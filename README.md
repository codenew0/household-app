# 💰 家計管理アプリ

Pythonで作られたデスクトップ家計管理アプリです。月ごとの支出・収入を項目別に記録・集計・分析できます。

## 入力支援・家計の確認

- **未確定の一括確認**：「入力・管理」メニューから開きます。全期間の未確定を初期表示し、年月・キーワードで絞り込み、複数選択して確定／削除できます。Ctrl+Aで検索結果を全選択。確定は確認画面を挟み、ポイントを差し引いた現金分だけ支出へ計上します。
- **日付順の明細一覧**：「📅 XX月」ボタン、または「検索・分析」メニューから開きます。表画面は残し、一覧では支払方法・ポイント・メモ・未確定状態をまとめて確認できます。選択行の支出・収入を別々に集計し、詳細編集もできます。
- **OCRの入力候補**：OCR画面で支払先を入力し「支払先から分類・支払方法を提案」を押すと、確定済み履歴で最も多い組を提案します。確認後に反映します。
- **予算・残額・前月比較**：「検索・分析」から開きます。年月欄を押すと白背景・黒文字のカレンダーが開き、年と月を選ぶとすぐ表示を更新します。年月の直接入力はできません。月全体または分類を選んで予算を保存し、支出・残額・前月支出・増減を表示します。超過は赤字です。月全体と分類別の予算は独立しており、自動配分はしません。未確定とポイント利用分は支出に含めません。
- **定期支払い見込み**：設定一覧に次回支払日を表示し、支払間隔・開始時期・支払回数を反映した今後12か月の予定額を集計します。
- **OCRの左右比較**：左に元画像、右に商品候補と入力欄を表示します。商品選択時は画像上の該当行へ移動し、枠と拡大画像で照合できます。中央の仕切りで左右の幅を変えられます。
- **CSV重複候補**：取り込み前に日付・支払先・利用前金額を照合します。候補一覧を見て「取り込む」か「キャンセルして見直す」を選択できます。自動削除はしません。上書き時は既存行ではなく、CSV内部の重複だけを確認します。

## 削除・上書きの復元

明細の保存・一括確定／削除・分類削除・CSV取り込みの前に、`household_json/restore_points` へ全期間の明細と設定のスナップショットを保存します。「データ」→「バックアップから復元」で保存日時・操作・件数を選べます。復元ポイントは新しい50件を保持します。

**復元は1件だけの取り消しではなく、明細・分類・支払方法・定期支払い設定・予算をその時点へ戻す操作です。** 復元後に追加したデータも戻るため、確認して実行してください。復元操作直前も保存します。古い復元ポイントは50件を超えると自動削除されます。バックアップも個人情報を含むため、データフォルダ全体を適切に管理してください。

メニューバーは用途別に分類しています。

- **データ**：CSVインポート・エクスポート
- **入力・管理**：レシートOCR、定期支払い
- **検索・分析**：検索（Ctrl+F）、図表

検索・図表・CSVは従来のヘッダーボタンからも開けます。レシートOCR・定期支払いはメニューから開きます。

## 定期支払い・ポイント・レシートOCR

支払方法はプルダウンから選択します。定期支払い・OCR画面の支払方法欄にある「管理」、または詳細画面の「支払方法の管理」から候補を追加・削除できます。候補は各画面で共通で、再起動後も保存されます。候補を削除しても登録済み明細の支払方法は変更されません。

OCRと定期支払いの画面は下部の操作ボタンが固定表示されます。内容が収まらない場合は右側のスクロールバーで移動してください。

「入力・管理」→「定期支払い」から、サブスクリプション・家賃・公共料金・分割払いを登録できます。名前、支払先、1回の金額、支払日、支払方法、開始日、登録先の分類、支払・更新間隔を指定でき、分割払いには支払回数も設定できます。編集、停止、削除も可能です。支払日が存在しない月は月末に登録します。開始日より前の支払分は作成しません。

自動登録を停止していた期間の明細は、再開時にさかのぼって作成しません。

アプリは起動時と起動中の1分ごとに支払日を確認します。アプリ終了中の分は次回起動時にまとめて登録します。自動明細は設定した分類へ未確定として追加され、月次支出・グラフ・検索の合計から除外されます。詳細画面でOKを押すと、その画面の明細が確定して集計に含まれます。キャンセル・Esc・×では確定されません。自動明細を削除した場合、同じ設定の同じ支払月の明細は再作成されません。

明細の「金額」はポイント利用前の金額です。「ポイント」は別欄に入力し、1ポイント＝1円として差し引きます。例：1,000円の商品に200ポイントを使った場合、金額1000円・ポイント200と入力し、支出は800円になります。全額ポイントなら支出は0円です。利用ポイントは金額以下で入力してください。月別JSON・CSVには利用前の金額とポイントを別々に保存し、支出合計には差し引いたお金での支払額だけを計上します。

「レシートOCR」から画像を読み込むと認識した文字が行単位で表示されます。商品行を選び、日付・分類・支払先・ポイント利用前の金額・ポイント・メモを確認して「確認した明細を追加」を押してください。商品ごとに別分類を指定できます。下の一覧を確認して「一覧の明細を登録」でまとめて保存します。読み取り値は修正でき、登録前の一覧から削除もできます。合計・税額などの商品以外の行を重複登録しないよう確認してください。

OCRはWindows標準の日本語OCRを端末内で実行します。日本語OCR機能が利用できないPCでは、Windowsの言語設定から日本語のOCR機能を追加してください。大きな画像は文字認識前に縮小し、画像の向き情報も反映します。画像は外部サービスへ送信しません。

OCRの商品名・金額は文字の座標で同じ行へ対応付けます。「108軽」などの税率記号付き価格にも対応し、商品サイズやポイント残高を価格として扱わないようにしています。行ごとの再認識、英語OCRが利用可能な場合の価格欄の数字認識、横幅・コントラスト補正も行います。商品候補は名前・金額の表に表示され、選択すると元画像の該当行を確認できます。認識には誤りが残るため、メモと金額を確認・修正してから追加してください。読み落としは金額空欄で表示します。合計・税・ポイント等の行は「認識した全文・その他の行を表示」で確認できます。

CSVには従来の列に加えて「ポイント・支払方法・状態・自動登録ID」が追加されています。従来の8列CSVも読み込めます。明細の先頭3項目だけの既存JSONも引き続き読み込めます。

## メイン表 — 月次カレンダー形式の家計表

<!-- スクリーンショット: メイン表のアップ。合計行・まとめ行が見えている状態 -->
![メイン表](https://github.com/user-attachments/assets/8eb5eaa6-055d-4c85-930f-f933c985a9dc)

月の日付が縦に並び、支出項目が横に並ぶ表形式で家計を管理します。

**デフォルト項目（列）:**

| 列名 | 説明 |
|------|------|
| 交通 | 電車・バス・タクシーなど |
| 外食 | レストラン・カフェなど |
| 食料品 | スーパー・コンビニなど |
| 日用品・雑貨 | 生活消耗品など |
| 通販 | ネット通販など |
| ゲーム関連 | ゲーム・周辺機器など |
| サブスク | 定期購読サービスなど |
| 家賃・宿泊 | 家賃・ホテルなど |
| 光熱・通信 | 電気・ガス・水道・スマホなど |
| 医療・美容 | 病院・薬局・美容院など |
| イベント | 旅行・冠婚葬祭など |

**表の特殊行:**

- **合計行** — 各項目の月間合計を自動集計
- **まとめ行** — 収入・収支差額・総支出を表示

**土日の色分け:** 土曜日・日曜日は背景色で視覚的に区別されます。

**年・月の切り替え:**

- メイン画面の年表示・左右ボタン・01〜12の月ボタンは元の見た目と配置を維持します。年表示を押すと年月選択パネルを開きます。
- 明細一覧は元の開始・終了年月欄を維持します。各欄をクリックすると同じ年月選択パネルを開きます。
- パネルはメイン画面ではボタンに合わせた灰色背景・白文字、明細一覧では白背景・黒文字です。年見出しと1〜12月の4列×3行グリッドを表示し、選択中の月を強調します。
- ポップアップ上部は `◀ 2020年 ▶`。左右のボタンで年を切り替え、月を選ぶと確定して閉じます。外側クリック・Escはキャンセルです。
- 明細一覧では開始・終了が同じ月でも、クリックした欄だけを変更します。もう一方の年月は変わりません。

## 支出詳細ダイアログ — セルごとの明細入力

<!-- スクリーンショット: 詳細入力ダイアログ（複数行入力されている状態） -->
![支出詳細ダイアログ](https://github.com/user-attachments/assets/b6589b82-72e6-4aad-a350-ae2de1afbbd2)

メイン表のセルをダブルクリックすると、その日・その項目の詳細を入力できます。1つのセルに複数の明細（支払先・金額・メモ）を登録でき、セルの表示金額は自動的に合算されます。

**列:**
- **支払先** — 過去の入力履歴からドロップダウンで補完
- **金額（円）**
- **メモ** — 過去のメモ入力履歴からTABキーで補完

**操作:**
- ダブルクリック / `Space` キーでセルを編集
- `Tab` キーで自動補完（支払先・メモ）
- `Enter` で編集確定
- 最終行に入力すると自動で新しい空行が追加
- `Ctrl+Z` で元に戻す（最大50操作）
- 行のコピー・切り取り・貼り付け・削除（右クリックメニューまたはショートカット）

## 検索

<!-- スクリーンショット: 検索ダイアログ（検索結果が表示されている状態） -->
![検索ダイアログ](https://github.com/user-attachments/assets/0c02dce6-29d9-44a7-b99c-826fe82e80c4)

`Ctrl+F` または画面上部の「🔍 検索」ボタンで全期間のデータを横断検索できます。

**検索対象:** 支払先・利用前金額・ポイント・支払方法・メモ・状態の部分一致（大文字小文字を区別しない）

**検索結果の機能:**
- 年月日・分類・支払先・利用前金額・ポイント・現金支払額・支払方法・メモ・状態を一覧表示
- 各列のヘッダーをクリックしてソート（昇順/降順の切り替え）
- 検索結果の **現金支払額の合計・平均** を下部に表示。未確定は0円として扱い、赤文字で表示
- 複数行を選択して右クリックし、選択行の合計金額を計算
- 行をダブルクリックするとメイン表の該当行に直接ジャンプ・選択

## CSVインポート・エクスポート

ヘッダーの `CSV` ボタンから、開始年月と終了年月を指定して入出力できます。各年月欄を押すと白背景・黒文字のカレンダーが開きます。年月欄へ直接入力はできません。

- **エクスポート** — 指定期間の明細をUTF-8 BOM付きCSVで保存
- **追加インポート** — 既存明細を残し、CSVの明細を追加
- **上書きインポート** — 指定期間の既存明細を削除し、CSV内容で置き換え

CSVの列は `年,月,日,列番号,項目,支払先,金額,メモ` です。期間外の行はインポート時に無視されます。

## 明細一覧

旧「月間データ詳細」は明細一覧へ統合しました。「📅 XX月」ボタンまたは「検索・分析」→「明細一覧」から開き、選択中の月に絞った明細を表示します。開始・終了年月を変更すれば複数月をまとめて確認できます。専用の「明細一覧」ボタンは廃止しました。

- 日付・分類・支払先・利用前金額・ポイント・現金・支払方法・メモ・状態を表示。
- 各列の見出しで昇順／降順を切り替え。金額は数値順です。
- キーワード・未確定で絞り込み、複数選択した行の収入・支出・確定支出の平均を表示。
- ダブルクリックで詳細編集。右クリックの「メイン表の該当セルへ移動」で表へ戻れます。
- 表示内容が一致する重複候補は薄赤の背景、未確定は赤文字。候補の自動削除はしません。
- 一括確定・削除に対応。明細の再利用には既存のコピー＆ペーストを使います。
- 縦横スクロール、見出しの右クリックによる列幅リセットに対応。

## グラフ — 項目別月間推移

<!-- スクリーンショット: グラフダイアログ（折れ線グラフが表示されている状態） -->
![グラフ](https://github.com/user-attachments/assets/b82a76f7-d509-425b-87d1-5b66fbe429c8)

「📊 図表」ボタンをクリックすると、月ごとの支出推移を折れ線グラフで確認できます。

**グラフの種類:**
- **総支出** — 全項目の月間合計推移
- **総収入** — 月間収入の推移
- **各項目** — 項目ごとの月間推移

**操作:**
- 上部のタブで項目を切り替え
- 右上のドロップダウンで対象年を切り替え
- データポイントに金額ラベルを表示

## データ保存・バックアップ

データは自動でJSONファイルに保存されます。

```
json/
├── settings.json        # カスタム列・支払先履歴などの設定
└── data/
    └── 2025/
        ├── 2025_01.json  # 2025年1月のデータ
        ├── 2025_02.json
        └── ...
```

- 編集のたびに **即時自動保存**
- アプリ終了時に **バックアップファイル** を自動生成

## 動作環境

- Python 3.10 以上
- Windows（推奨）/ macOS / Linux

## インストール

```bash
git clone https://github.com/yourname/household-app.git
cd household-app
pip install matplotlib psutil
python main.py
```

```bash
pip install pyinstaller
```
